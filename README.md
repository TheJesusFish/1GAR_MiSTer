# 1 Game ALL Roms
This is 1 Game All Roms and it's exactly what it says on the tin.

A lot of MiSTer sets (and sets for other FPGA systems) focus on being as lean as possible. 1 Game 1 Rom, no bloat. This is the opposite.

It's 100% bloat

It uses the Redump, No-Intro, TOSEC and T-En Collection to give you every version of every rom for your MiSTer.
- CD Images are all bin/cue for maximum compatability
- Rom files are unzipped

# So What IS it?
Instead of sorting your game folders by region or language or whatever, they are sorted by games. Every Console folder's top level is a folder for every game on that console. Inside of those folders are roms/cd images of every version of that game that is available in the above collections.

Translations and hacks also live in that folder, but they are forced to the bottom of the list with a '~'

The whole collection is around 8tb, so plan for that.
